
# Leetcode-1545. Find Kth Bit in Nth Binary String
## 題目說明
給定兩個正整數 `n` 和 `k`，二進位字串 `Sn` 的建構如下：

S1 = "0"

Si = Si - 1 + "1" + reverse(invert(Si - 1)) for i > 1

其中，+ 表示字串拼接操作，`reverse(x)` 傳回反轉後的字串 `x`，`invert(x)` 將 `x` 中的所有位元取反（0 變成 1，1 變成 0）。

例如，上述序列中的前四個字串為：

S1 = "0"

S2 = "011"

S3 = "0111001"

S4 = "011100110110001"

傳回 `Sn` 中的第 `k` 位。保證對於給定的 `n`，`k` 是有效的。

### 限制條件：
- `1 <= n <= 20`。
- `1 <= k <= 2＾n - 1`。

## 解題思路

這道題目的字串生成規則為：$S_n = S_{n-1} + "1" + reverse(invert(S_{n-1}))$。
如果直接模擬生成字串，空間複雜度會達到 $O(2^n)$，當 $n=20$ 時會消耗極大記憶體。

### 1. 核心邏輯：對稱性與分治
觀察 $S_n$ 的結構，可以發現它由三部分組成：
1.  **左半部**：完全等於 $S_{n-1}$。
2.  **中間位**：永遠是 `"1"`。
3.  **右半部**：是 $S_{n-1}$ 翻轉且反轉後的結果。

透過這層關係，我們可以從 $S_n$ 逆推回 $S_{n-1}$，直到回到最基礎的 $S_1 = "0"$。



### 2. 演算法步驟 (Iterative approach)
我們使用一個布林值 `invertCount` 來記錄路徑中經過了幾次「反轉」：

1.  **計算長度**：$S_n$ 的長度固定為 $2^n - 1$。
2.  **判斷 $k$ 的位置**：
    * **正好在中間 ($k == mid$)**：中間位固定為 `'1'`。但如果之前路徑反轉次數為奇數，則變為 `'0'`。
    * **在左半部 ($k < mid$)**：$S_n$ 的左半部與 $S_{n-1}$ 完全相同，$k$ 值不變，繼續往 $n-1$ 找。
    * **在右半部 ($k > mid$)**：右半部是左半部的「鏡像且反轉」。
        * **座標變換**：新的 $k = length - k + 1$（對應回左半部的位置）。
        * **狀態更新**：標記 `invertCount` 切換一次（因為右半部被 `invert` 過）。
3.  **基礎情況**：如果一直推到 $S_1$（此時 $n=1$），其值為 `'0'`。最後根據 `invertCount` 決定回傳 `'0'` 還是 `'1'`。

---

### 3. 圖解範例：n=3, k=1
$S_1 = 0$
$S_2 = 0 + 1 + 1 = 011$
$S_3 = 011 + 1 + 001 = 0111001$

若找 $S_3$ 的 $k=7$：
- $S_3$ 長度 7，中間位 $mid=4$。
- $k=7 > 4$，在右半部。
- 更新 $k = 7-7+1 = 1$，`invertCount = true`。
- 降至 $S_2$ 找 $k=1$。
- $S_2$ 長度 3，中間位 $mid=2$。
- $k=1 < 2$，在左半部。$k$ 不變，繼續降至 $S_1$。
- 最終 $S_1$ 基礎值為 `0`，因 `invertCount` 為 `true`，結果為 `1`。



---

### 4. 效能分析
| 維度 | 複雜度 | 說明 |
| :--- | :--- | :--- |
| **時間複雜度** | $O(n)$ | 每次迴圈 $n$ 減 1，最多執行 $n$ 次。 |
| **空間複雜度** | $O(1)$ | 只使用常數個變數，沒有遞迴堆疊或字串儲存空間。 |

## 參考解法
```cpp title="C++" showLineNumbers
class Solution {
public:
    char findKthBit(int n, int k) {
        bool invertCount = false;
        
        while (n > 1) {
            int length = (1 << n) - 1;
            int mid = length / 2 + 1;
            
            if (k == mid) {
                // 找到中間位 '1'，根據目前的翻轉狀態決定輸出
                return invertCount ? '0' : '1';
            } 
            else if (k > mid) {
                // 如果在右側，進行翻轉邏輯：更新 k 並標記反轉一次
                k = length - k + 1;
                invertCount = !invertCount;
            }
            // 如果在左側 (k < mid)，k 不變，繼續找 n-1
            n--;
        }
        
        // 最終回到 n=1，原始值是 '0'
        return invertCount ? '1' : '0';
    }
};
```
