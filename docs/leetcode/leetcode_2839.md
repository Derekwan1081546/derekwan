
# Leetcode-2839. Check if Strings Can be Made Equal With Operations I
## 題目說明
給定兩個長度皆為 `4` 的字串 `s1` 與 `s2`，皆由小寫英文字母組成。

你可以對任一字串執行下列操作任意多次：

- 選擇兩個索引 `i` 與 `j`，且滿足 `j - i = 2`，然後交換字串中這兩個位置的字元。

若可以透過上述操作使 `s1` 與 `s2` 相等，回傳 `true`，否則回傳 `false`。

### 限制條件：
- `s1.length == s2.length == 4`。
- `s1` 與 `s2` 僅由小寫英文字母組成。


## 解題思路

這段程式碼的目標是解決 **LeetCode 2839. Check if Strings Can be Made Equal With Operations I**（判斷兩字串是否可透過操作變得相等）。
題目的核心觀察在於：每次交換的兩個索引 `i` 與 `j` 必須滿足 `j - i = 2`，這代表 **只有相同奇偶性的索引可以互換位置**。
也就是說：

- 索引 `0` 與 `2` 之間可以互換。
- 索引 `1` 與 `3` 之間可以互換。
- 但「偶數索引」與「奇數索引」之間 **永遠無法互換**。

因此 `s1` 能變為 `s2` 的充分必要條件是：
`s1` 中偶數位置的字元（多重集合）與 `s2` 中偶數位置相同，且奇數位置也相同。

### 演算法步驟

本程式採用「**模擬交換**」的方式直接驗證：

1.  **逐位元比對並交換**：
    從 `i = 0` 走到 `s1.size() - 3`（即 `i = 0, 1`，因為長度為 4），對每個位置：
    * 若 `s1[i] != s2[i]`，就將 `s1[i]` 與 `s1[i + 2]` 交換（利用允許的距離為 2 的操作）。
    * 這個動作的意義是：嘗試把同奇偶性中另一端的字元換過來，使其與 `s2[i]` 對齊。

2.  **最終比對**：
    操作完成後，若 `s1 == s2` 則代表可達成；否則代表 `s1` 與 `s2` 在某個奇偶分組中字元不一致，無論如何交換都不可能相等，回傳 `false`。

### 為何只需走到 `size() - 2`？

字串長度為 4，索引 `0、1` 與 `2、3` 屬於同一個奇偶群組。只要修正前兩個位置 (`i = 0` 處理偶數群組、`i = 1` 處理奇數群組)，後兩個位置 (`i = 2、3`) 自然就是另一端的結果，不需要再額外處理。

---

### 複雜度分析

* **時間複雜度：$O(N)$**
  其中 $N$ 為字串長度（題目固定為 4，可視為 $O(1)$）。迴圈與最終字串比對皆為線性時間。

* **空間複雜度：$O(1)$**
  僅在原字串上進行交換，沒有配置額外的資料結構。
## 參考解法
```cpp title="C++" showLineNumbers
class Solution {
public:
    bool canBeEqual(string s1, string s2) {
        for (int i = 0; i < s1.size() - 2; i++) {
            if (s1[i] != s2[i]) {
                swap(s1[i], s1[i + 2]);
            }
        }
        return s1 == s2 ? true : false;
    }
};
```
