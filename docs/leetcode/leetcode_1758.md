
# Leetcode-1758. Minimum Changes To Make Alternating Binary String
## 題目說明
給定一個只包含字元 `'0'` 和 `'1'` 的字串 `s`。在一次操作中，你可以將字串中的任意一個字元從 `'0'` 變成 `'1'`，或從 `'1'` 變成 `'0'`。

如果字串中相鄰的任兩個字元都不相等，則此字串稱為「交替字串」。例如，`"010"` 是交替字串，而 `"0100"` 則不是。

請回傳使 `s` 變成交替字串所需的最少操作次數。

### 限制條件：
- `1 <= s.length <= 10^4`
- `s[i]` 只會是 `'0'` 或 `'1'`

## 解題思路
這題的解法重點在於：「交替字串只有兩種形式：`0101...` 或 `1010...`」。因此，我們只要比較原始字串與這兩種標準交替模式的差異次數，取最小值即可。

具體步驟如下：
1. 先假設目標字串為 `0101...`。從左到右遍歷原始字串 `s`，對每個位置 `i` 檢查預期字元應該是 `'0'` 還是 `'1'`。
2. 如果 `s[i]` 與這種模式不一致，就需要一次操作，計數 `count0++`。
3. 同樣地，假設目標字串為 `1010...`，再次從左到右遍歷，統計 `s[i]` 與該模式不一致的次數 `count1++`。
4. 兩種模式中較小的計數就是答案，因為只需將字串改成其中一種交替形式。

這個方法之所以正確，是因為：
- 任何交替字串必定與其中一種模式完全一致；
- 最少操作數就是把每個錯誤位置翻轉成該模式的字元；
- 兩種模式都可能是最優解，因此要比較後取最小值。

- 時間複雜度：O(n)，其中 `n = s.length()`，只需一次遍歷進行兩種模式的比較。
- 空間複雜度：O(1)，僅使用常數個整數變數進行計數。

## 參考解法
```cpp title="C++" showLineNumbers
class Solution {
public:
    int minOperations(string s) {
        int count = 0;
        int n = s.length();
        for (int i = 1; i < s.size(); i++) {
            if (s[i - 1] == '0') {
                if (s[i] == '0') {
                    s[i] = '1';
                    count++;
                }
            } else {
                if (s[i] == '1') {
                    s[i] = '0';
                    count++;
                }
            }
        }
        return min(count, n - count);
    }
};
```
