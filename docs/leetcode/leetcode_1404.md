
# Leetcode-1404. Number of Steps to Reduce a Number in Binary Representation to One
## 題目說明
給定一個整數的二進位表示字串 `s`，傳回在以下規則下將其化簡為 `1` 所需的步驟數：

如果目前數字為偶數，則需要將其除以 `2`。

如果目前數字為奇數，則需要將其加 `1`。

保證所有測試用例都能達到 `1`。

### 限制條件：
- `1 <= s.length <= 500`。

- `s` 由字元 `'0'` 或 `'1'` 組成。

- `s[0] == '1'`。

## 解題思路

這題的核心挑戰在於處理「二進位的大數加法」。題目給予兩個操作：
1.  **若為偶數**：除以 2（二進位向右移一位，等同於刪除最後一個 `0`）。
2.  **若為奇數**：加上 1（二進位加法，可能產生連鎖進位）。

### 1. 核心邏輯：從低位元 (LSB) 往高位元處理
我們不需要真的去模擬字串的加法與刪除，只需要維護一個 **進位標記 (`carry`)**，並從字串末端向前遍歷。

* **遇到 0**：
    * 若無進位 ($0+0$)：它是偶數，執行「除以 2」需 **1 步**。
    * 若有進位 ($0+1$)：它變成奇數，需「加 1」再「除以 2」共 **2 步**，且進位持續。
* **遇到 1**：
    * 若無進位 ($1+0$)：它是奇數，需「加 1」再「除以 2」共 **2 步**，產生進位。
    * 若有進位 ($1+1$)：它變成偶數 ($2$)，執行「除以 2」需 **1 步**，進位持續。

### 2. 演算法規則總結
遍歷從 `i = s.size() - 1` 到 `1`：
- 計算當前位元值：`currentBit = s[i] + carry`。
- **如果 `currentBit` 是 1 (奇數)**：
    - 步數 `+2`（一步加 1，一步除以 2）。
    - 進位 `carry = 1`。
- **如果 `currentBit` 是 0 或 2 (偶數)**：
    - 步數 `+1`（直接除以 2）。
    - 進位維持：若原本是 2 則進位為 1，否則為 0。



---

### 3. 最後一關：處理最高位 (s[0])
字串的第一位 `s[0]` 必定是 `1`。當迴圈結束後，我們只需要考慮最後剩下來的進位：
- 如果 `carry == 0`：最高位的 `1` 已經是最終結果，不需額外步驟。
- 如果 `carry == 1`：最高位的 `1` 加上進位變成 `10`（二進位），我們還需要 **1 步**「除以 2」才能變回 `1`。
- 因此，結果為 `steps + carry`。

---

### 4. 效能分析
| 維度 | 複雜度 | 說明 |
| :--- | :--- | :--- |
| **時間複雜度** | $O(N)$ | $N$ 為字串長度。我們只需從後往前遍歷一次字串。 |
| **空間複雜度** | $O(1)$ | 只使用了兩個整數變數（steps, carry），不需要額外空間。 |

---

## 參考解法
```cpp title="C++" showLineNumbers
class Solution {
public:
    int numSteps(string s) {
        int steps = 0;
        int carry = 0;

        // 我們處理到 index 1 即可，index 0 (最高位) 最後單獨判斷
        for (int i = s.size() - 1; i > 0; i--) {
            int currentBit = (s[i] - '0') + carry;

            if (currentBit == 1) {
                // 奇數：需要 +1 操作 (1步) 變偶數，再除以 2 (1步)
                steps += 2;
                carry = 1; // 產生進位
            } else {
                // 偶數 (0+0 或 1+1): 只需要除以 2 (1步)
                steps += 1;
                // 如果 currentBit 是 2 (1+1)，進位維持 1；如果是 0，進位維持 0
                carry = (currentBit == 2) ? 1 : 0;
            }
        }

        // 最後看最高位 (s[0] 必定是 '1') 加上最後的進位
        // 如果 carry 是 1，代表變成 1+1 = 10，還需要一步除法變回 1
        return steps + carry;
    }
};
```
