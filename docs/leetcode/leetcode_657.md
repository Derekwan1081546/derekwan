# Leetcode-657. Robot Return to Origin

## 題目說明
一個機器人從 2D 平面的原點 `(0, 0)` 出發。給定一個字串 `moves` 代表機器人的移動序列，其中每個字元代表一次移動：

- `'U'`：向上移動一格。
- `'D'`：向下移動一格。
- `'L'`：向左移動一格。
- `'R'`：向右移動一格。

判斷機器人在完成所有移動後是否回到原點 `(0, 0)`。若是則回傳 `true`，否則回傳 `false`。

**注意**：機器人的「面朝方向」無關緊要，`'R'` 永遠代表向右移動一格，其餘同理。每次移動的距離相同。

### 限制條件：
- `1 <= moves.length <= 2 * 10^4`。
- `moves` 只包含字元 `'U'`、`'D'`、`'L'`、`'R'`。

## 解題思路

本題只需追蹤機器人的座標變化，最後檢查是否回到原點。

### 演算法步驟

1. 初始化座標 `x = 0, y = 0`。
2. 遍歷字串中每個字元：
   - `'U'`：`y++`
   - `'D'`：`y--`
   - `'R'`：`x++`
   - `'L'`：`x--`
3. 最終判斷 `x == 0 && y == 0`，若成立則機器人回到原點。

---

### 複雜度分析

* **時間複雜度：$O(n)$**，其中 $n$ 為字串長度，僅需一次線性掃描。
* **空間複雜度：$O(1)$**，只使用兩個整數變數。

## 參考解法
```cpp title="C++" showLineNumbers
class Solution {
public:
    bool judgeCircle(string moves) {
        int x = 0;
        int y = 0;

        for (char m : moves) {
            if (m == 'U') {
                y++;
            } else if (m == 'D') {
                y--;
            } else if (m == 'R') {
                x++;
            } else if (m == 'L') {
                x--;
            }
        }

        // 只要 x 和 y 都是 0，代表回到原點
        return x == 0 && y == 0;
    }
};
```
