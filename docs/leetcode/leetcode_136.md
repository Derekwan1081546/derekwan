# Leetcode-136. Single Number
## 題目說明
給定一個**非空**整數陣列 `nums`，其中每個元素都出現**兩次**，只有一個元素只出現**一次**。找出那個只出現一次的元素。

你必須實現一個線性時間複雜度的解法，且只能使用常數額外空間。

範例1：

- 輸入：`nums = [2,2,1]`
- 輸出：`1`

範例2：

- 輸入：`nums = [4,1,2,1,2]`
- 輸出：`4`

範例3：

- 輸入：`nums = [1]`
- 輸出：`1`

### 限制條件：
- `1 <= nums.length <= 3 * 10^4`
- `-3 * 10^4 <= nums[i] <= 3 * 10^4`
- 陣列中每個元素都出現兩次，只有一個元素只出現一次。

## 解題思路
利用 XOR（位元互斥或）的特性來解題：

- `a ^ a = 0`：相同的數字 XOR 後為 0。
- `a ^ 0 = a`：任何數字與 0 做 XOR 結果為自身。
- XOR 運算滿足交換律與結合律。

因此，將陣列中所有元素依序進行 XOR 運算，出現兩次的元素會互相抵消變為 0，最終剩下的結果就是只出現一次的那個元素。

- **時間複雜度**：O(n)，遍歷陣列一次。
- **空間複雜度**：O(1)，只使用一個變數儲存結果。

## 參考解法1
```cpp title="C++ Solution 1: XOR" showLineNumbers
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int ans = 0;
        for (auto& n : nums) {
            ans ^= n;
        }
        return ans;
    }
};
```
