
# Leetcode-191. Number of 1 Bits
## 題目說明
給定一個正整數 `n`，寫一個函數，傳回其二進位表示中置位的位數（也稱為漢明權重 `Hamming weight`）。

### 限制條件：
- `1 <= n <= 2＾31 - 1`。

## 解題思路

這道題目的核心目標是計算一個整數在二進位表示法中，共有多少個個位數為 `1` 的位元。

### 1. 核心邏輯：進位制轉換原理
你的解法採用了**「除 2 取餘數」**法，這與將十進位轉為二進位的邏輯完全一致：
- **檢查最後一位**：`n % 2` 可以得知當前二進位的最低位（Least Significant Bit, LSB）是 `0` 還是 `1`。
- **計數**：如果餘數為 `1`，代表該位元是 `1`，計數器 `count` 加一。
- **右移（縮小範圍）**：`n = n / 2` 等同於將二進位向右移動一位，丟棄已經檢查過的最低位。

### 2. 演算法步驟
1.  初始化 `count = 0`。
2.  進入 `while` 迴圈，條件為 `n > 0`（當還有位元需要處理時）：
    * 使用 `if (n % 2 == 1)` 判斷目前最低位是否為 `1`。
    * 執行 `n = n / 2` 處理下一個位元。
3.  當 `n` 變為 `0` 時跳出迴圈，回傳 `count`。

---

### 3. 效能分析
| 維度 | 複雜度 | 說明 |
| :--- | :--- | :--- |
| **時間複雜度** | $O(\log n)$ | 迴圈次數取決於 $n$ 的位元長度。對於 32 位元整數，最多執行 32 次。 |
| **空間複雜度** | $O(1)$ | 只使用了常數個變數（count）。 |

---

### 4. 進階優化建議 (Bitwise Operations)
在 C++ 中，處理位元題目通常會使用**位元運算子**，效能會比算術運算（%、/）更高：

#### 方法 A：使用位元運算子改寫
將 `% 2` 改為 `& 1`，將 `/ 2` 改為 `>> 1`。
```cpp
while (n > 0) {
    count += (n & 1); // 檢查最後一位是否為 1
    n >>= 1;          // 右移一位
}

## 參考解法
```cpp title="C++" showLineNumbers
class Solution {
public:
    int hammingWeight(int n) {
        int count = 0;
        while (n > 0) {
            if (n % 2 == 1) {
                count++;
            }
            n = n / 2;
        }
        return count;
    }
};
```
