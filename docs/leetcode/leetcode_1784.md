
# Leetcode-1784. Check if Binary String Has at Most One Segment of Ones
## 題目說明
給定一個不含前導零的二進位字串 `s`，其中 `s` 僅包含字元 `'0'` 和 `'1'`，且 `s[0]` 保證為 `'1'`。

如果字串中至多只有一個連續的 `1` 區段，則回傳 `true`；否則回傳 `false`。

所謂的「連續 `1` 區段」，就是由一段接連的 `'1'` 所組成的子字串。例如，`"1100"` 只有一個 `1` 區段，`"101"` 則有兩個。

### 限制條件：
- `1 <= s.length <= 100`
- `s[i]` 只會是 `'0'` 或 `'1'`
- `s[0]` 是 `'1'`

## 解題思路
這題可以直接檢查字串中是否出現第二個 `1` 區段。因為字串保證從 `'1'` 開始，第一個 `1` 區段一定從開頭開始，後面只要再出現一次 `'0'` 之後又出現 `'1'`，就代表至少有兩個分離的 `1` 區段。

實作上只需從字串的第二個字元開始遍歷：
1. 遇到一個 `s[i] == '1'` 且前一個字元 `s[i-1] == '0'`。
2. 這種情況表示出現了新的 `1` 區段，因此字串中至少有兩個 `1` 區段，應該直接返回 `false`。
3. 如果整個遍歷結束都沒找到這種情形，則字串最多只有一個連續的 `1` 區段，返回 `true`。

重點在於：
- 第一個 `1` 區段必定從字串開頭開始；
- 只要再次從 `'0'` 轉換成 `'1'`，就已經違反「最多一個 `1` 區段」的條件；
- 因此只需要檢查是否存在一個位置 `i`，使得 `s[i-1] == '0'` 且 `s[i] == '1'`。

- 時間複雜度：O(n)，其中 `n = s.length()`，僅需一次線性掃描。
- 空間複雜度：O(1)，只使用常數級別的指標/計數變數。

## 參考解法
```cpp title="C++" showLineNumbers
class Solution {
public:
    bool checkOnesSegment(string s) {
        // 從第二個字元開始看 (索引 1)
        for (int i = 1; i < s.size(); i++) {
            // 如果前一個是 '0'，現在這個是 '1'
            // 這代表我們跨過了海洋，又跳到了另一座島上！
            if (s[i - 1] == '0' && s[i] == '1') {
                return false; // 發現第二個區段，判斷失敗
            }
        }
        // 走完全程都沒發現 "01"，代表只有開頭那一段 1
        return true;
    }
};
```
